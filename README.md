 # Design Decisions and Documentation
 1. The style is modeled after the Westminster High School website (whslions.net) and styled using Bootstrap
 2. To allow users to upload their own model, the program has a zip file upload

# Limitations and Future Development
1. The user must upload a zip file that contains three specific files named in a specific way: model.json, metadata.json, and weights.bin. We are considering allowing users to upload a Keras model (.h5 file extension) for use in Python environments.
